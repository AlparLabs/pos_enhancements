⚙️ Configuración Rápida

  1. Instalación: Instalar desde Apps → SIT POS Logo Customization
  2. Configuración: Ir a Punto de Venta → Configuración → Puntos de Venta
  3. Logo: Abrir sesión POS → Pestaña "Logo Personalizado"
  4. Subir: Activar "Usar Logo Personalizado" y subir imagen
  5. Dimensiones: Ajustar ancho y alto según necesidades
💡 Recomendación: Use imágenes en formato PNG con fondo transparente para mejores resultados. Dimensiones recomendadas: 200x60 píxeles para logos horizontales.

🔧 Especificaciones Técnicas

  • Formatos soportados: PNG (recomendado), JPG, SVG, GIF
  • Tamaño máximo: 5MB por imagen
  • Dimensiones óptimas: 200x60px (horizontal), 80x80px (cuadrado)
  • Cache: Optimizado con cache de 1 hora
  • Responsive: Breakpoints para tablet (768px) y móvil (480px)
